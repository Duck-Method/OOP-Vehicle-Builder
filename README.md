# OOP-Vehicle-Builder
This project is a CLI using TypeScript and OOP

## Description
This project uses what I have learned so far in TypeScript and OOP to create a modular backend of a CLI that prompts the user through the various options provided for creating a car, truck, or motorbike object and performing actions on that object.
